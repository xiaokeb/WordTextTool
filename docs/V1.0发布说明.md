# V1.0 — Word 文本处理工具

## 功能说明

- PyQt6 中文单页界面，支持缩放与滚动，动态规则表格只读展示，长规则可双击查看完整内容。
- 多选 DOCX 或扫描文件夹当前层级；重复、旧版 DOC、超大和不可读文件会提示跳过。
- 正文、普通/嵌套表格、页眉页脚、超链接显示文字替换；支持同段跨 Run 和软换行。
- 使用原文一次匹配，同位置最长规则优先，替换结果不再次参与规则；新文字继承首匹配字符格式。
- 后台顺序处理、进度、四类结果、当前文件完成后的安全取消与关闭。
- 源文件保持不变；无匹配不输出；临时保存重开验证后发布，同名文件自动编号。

## 使用说明

1. 下载 Release 附件中的 EXE，双击启动，无需安装 Python 或 Word。
2. 选择文件或文件夹，在“替换前：”“替换后：”输入内容并点击“添加规则”。删除规则须先选中一行再点击“删除规则”。
3. 替换后留空表示删除，须确认；查找内容应准确包含需要替换的完整名称，空格、标点、大小写和软换行需匹配。
4. 可指定输出文件夹，否则自动保存在源文件目录下的“修改版”子目录。
5. 点击“开始处理”，结束后查看四类结果。点击取消或关闭会等当前文档处理结束再停止。

## 首版边界

- 单文件最大 50 MiB，每条规则两侧各最多 10,000 字符；规则关闭即清空。
- 不支持 DOC 转换、跨独立段落、自动域、文本框、艺术字、批注、脚注/尾注、修订/内容控件文字。
- 含图片等复杂结构的 Run 作为保护边界；不提供规则导入导出、递归目录、正则、Excel/PDF 或文件名批量修改。
- 目标环境为 Windows x64。未在其他系统上承诺原子发布兼容性。
