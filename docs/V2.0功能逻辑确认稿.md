## 3. 界面与共用流程

- 增加“文本替换、记录编号、后缀管理”三个页签，属于 V2.0 对首版单页限制的显式调整；窗口标题和 EXE 名继续使用“Word 文本处理工具”。
- 文本替换页沿用现有精确、最长优先、非级联、同段跨 Run 规则，以及字段保护、只读规则表、显式增删按钮。双击用于查看详情。
- 各页拥有独立文件列表和参数；同一时刻全程序只运行一个批次，禁止跨页同时写文件。可切换查看其他页，但运行期间不可启动另一任务。
- 文件对话框多选；文件夹扫描保持单层。默认按文件名排序，显示完整路径提示；编号页允许显式上移/下移改变顺序。各页仍执行存在性、普通文件、可读性、50 MiB 限制和规范化去重。
- 运行前冻结文件顺序、参数、预览结果和输出目录。取消在单文件安全边界停止；等待线程真实结束后解锁或关闭窗口。
- 结果保留成功、无变化、跳过、失败的语义；Word 页继续显示“未匹配”。多步骤任务须展示每一步及实际产物，不能仅用总成功数掩盖 PDF 失败。

## 4. Excel 编号逻辑

### 4.1 输入和模板边界

- 本版先接受 `.xlsx`，不处理 `.xls`、`.xlsm`、`.xlsb`、加密工作簿或受保护的目标工作表。
- 建议编号和 PDF 均通过经过验证的本地办公软件自动化适配器完成，复用同一套工作簿访问与安全策略；因此这两个功能需要可用的 WPS 表格或 Microsoft Excel。Word 替换和后缀管理可独立使用。
- 选择这一方案是为了避免另一套读写引擎在复杂模板往返保存时丢失对象。纯 Python 编号是可选替代路线，但必须另外收窄模板支持范围并验收，不在本稿中同时实现两套编号引擎。
- 编号范围固定为从第一张到最后一张工作表；所有工作表必须可见、有效且未保护，否则拒绝该工作簿并提示原因，不静默跳过。每个工作簿内使用相同编号，序号按文件递增。
- 处理前预览每个文件的编号、工作表和输出路径。任何参数、文件内容或顺序变化后重新计算预览。

### 4.2 自动与固定模式

- 编号模板必须且只能包含一个小写 `yy` 占位符，例如 `项目-yy`；起始序号默认为 1，可输入正整数。
- 序号至少两位，`01…99、100…`，不截断。示例：起始 98，三个文件依次为 `项目-98、项目-99、项目-100`。
- 自动模式：模板生成的编号写入 E1:F1。
- 固定模式：在每张工作表第一行上方先插入一行，固定文本写入新 E1:F1，模板生成的递增编号写入 E2:F2；固定文本不能为空或纯空白。E2:F2 对应插行前 E1:F1，原有目标文字仍须预览确认。
- 每个有效入队文件在预览时分配序号；执行中某文件失败，其序号保留为空缺，后续文件不重新编号。添加阶段跳过的文件不占序号。
- “重置编号”只把界面起始序号恢复为 1 并重算预览，不修改任何文件。每次批次使用当前起始值，不在后台自动累加或持久化。
- 编号作为文字写入；以 `=` 等字符开头也不得写成公式。文本长度上限为 10,000 字符。

### 4.3 单元格与内容保护

- 目标已经精确合并为 E1:F1/E2:F2 时写左上角；两种模式均统一设置编号区域水平/垂直居中、加粗、Times New Roman 字体和文本格式。其他格式保持；未合并时按下述安全条件合并。
- 目标未合并时，只有 F1/F2 为空且不存在相交合并区域才允许合并；不得为了写编号拆开其他合并范围或清空 F 列已有数据。
- 相交合并、目标公式、工作表保护或目标含不支持对象时，报告具体原因，该文件不产生编号输出。
- E1/E2 已有普通文字且与新值不同时，在执行前汇总展示将被替换的内容，由用户一次确认；取消确认则不启动批次。预览后内容变化则拒绝该文件并要求重新预览。
- 对多工作表工作簿，先检查全部目标工作表，全部通过后才写入临时副本，避免只改其中一部分便报告成功。
- 无实际修改时不输出编号副本；在一键转换中允许继续从经验证的原工作簿导出 PDF，并明确注明编号无变化。

## 5. PDF 导出与一键转换

- 提供“写入编号、导出 PDF、一键转换”三个入口。“导出 PDF”处理当前所选工作簿；“一键转换”内部引用本次编号步骤的实际结果路径，不回头误读未编号源文件。
- 导出从第一张到最后一张的全部工作表，要求所有表可见有效，按工作簿顺序合为一个 PDF。保留纸张、方向、打印区域及原有表格内容；固定模式中原打印区域从第一行开始时，扩展以纳入插入的新首行，避免固定编号遗漏。全部列缩放到一页宽，高度不限，上下边距 1.3 cm、左右 0.9 cm。
- PDF 从临时工作副本导出，页面设置不得保存回源工作簿。输出解析后必须可读取且页数大于 0，再发布最终文件。
- 默认输出为每个源文件同级“修改版”目录；自定义输出目录必须存在且可写。编号副本用 `原名 - 编号版.xlsx`，独立导出用 `原名.pdf`，一键导出用 `原名 - 编号版.pdf`；同名分别递增序号避让，结果显示实际路径，不通过文件名猜测配对。
- 一键转换中编号失败则跳过该文件 PDF 步骤；编号已保存、PDF 失败时保留编号副本，整体结果标记失败并列明已完成步骤与失败原因。
- 在编号已保存、PDF 尚未开始时收到取消，可保留编号副本并跳过 PDF，明确显示“PDF 已取消”；进入 PDF 导出后按当前文件安全边界收尾。
- 首次使用时后台检测可用引擎，提供“自动、Microsoft Excel、WPS 表格”。自动模式在已验证的引擎中选择，展示实际引擎身份；单文件失败不自动切换引擎重做，防止结果不可追踪。
- 缺少引擎或必要安全能力时，编号/PDF 按钮给出中文原因，其他模块正常使用。暂不引入 LibreOffice 或 reportlab 回退路线。
- COM 初始化、调用和释放发生在同一后台执行线程。只关闭本工具创建并能确认归属的工作簿及实例；不能接管、退出或按进程名杀死用户正在使用的办公软件。无法安全建立独立实例的适配器标记不可用。
- COM 调用卡住属于必须验证的失效场景：UI 保持响应并展示等待状态，不使用线程强杀；如果真实测试显示无法可靠收尾，应修复隔离机制后才能将该引擎列为本版已支持。

## 6. 文件名后缀管理

- 支持显式选择本地普通文件；文件夹保持单层扫描。只变更文件名，不改变所在目录和扩展名，不处理目录。
- 默认匹配串为现有产物实际使用的 ` - 修改版`（前有空格）；可自定义为 Wiki 的 `-修改版`。匹配区分大小写、空格精确，预览显示空格差异。
- 默认仅移除扩展名前的一个末尾匹配串；提供显式“移除主文件名中全部匹配串”选项以对应 Wiki 行为。`报告 - 修改版 (1).docx` 默认不匹配末尾，可通过预览后选择全部匹配模式处理。
- 不对扩展名应用替换；不自动去除其他首尾空白。匹配串不能为空；结果为空、含非法字符、保留设备名、结尾空格/点或越过原目录时拒绝。
- 预览显示“原名 → 新名 → 是否冲突/原因”；无匹配或名称相同计入无变化。
- 按预览顺序统一预留目标名，既避让磁盘已有文件，也避让同批次目标；冲突追加 ` (1)`、` (2)`。所有本批源路径视为占用，不执行交换文件名或覆盖其他源文件。
- 点击执行后对预览清单做一次重命名确认。执行时重新核验源文件身份和目标空闲状态；若目标被外部程序抢占则跳过并要求重新预览，不静默改成用户未看到的新名称。
- 这是唯一直接改变所选源文件路径的功能；文件内容不得变化。失败隔离，取消后保留已完成重命名并列明结果，不承诺整个批次原子回滚。

## 9. 提交与发布顺序

1. 全部功能实现 → 集中功能/安全测试 → 修复及必要复测 → 最终代码审查。
2. 测试和审查满足已确认验收范围后，更新版本说明和锁定依赖，使用 WordMod 构建 V2.0，验证最终 EXE 的实际新功能并记录 SHA256。产物验证失败则修复重建，不发布。
3. 核对远端实际分支及标签，保护已有 V1.0 标签和历史产物；旧 V1.0 待补发记录不能误标为已发布，不把新 EXE 上传到旧标签。
4. 明确选择项目文件，排除用户 `.idea/`，生成包含功能、使用方法、变更、验证和限制的中文统一提交；为该发布提交创建未占用的 V2.0 标签。
5. 普通推送分支和新标签，确认成功后创建 GitHub Release，上传本次验证的 EXE、README 和校验文件，核对附件与提交对应关系。
6. 网络或鉴权失败如实记录待同步；不强推、不移动已存在标签、不把待执行写成完成。缺少外部权限时仅请求实际必要的权限。

## 10. 技术资料与设计取舍依据

- [openpyxl 官方教程](https://openpyxl.readthedocs.io/en/3.1/tutorial.html) 提示并非所有 Excel 对象都能完整读回，因此本稿推荐编号与 PDF 共用经过真实验证的办公引擎；该建议不代表办公引擎已通过验证。

- [Microsoft PDF 导出接口](https://learn.microsoft.com/en-us/office/vba/api/excel.worksheet.exportasfixedformat) 用于设计导出适配边界。
- [WPS 工作簿接口](https://open.wps.cn/documents/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Workbook/obj) 和 [WPS 自动化安全属性](https://open.wps.cn/documents/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Application/member/AutomationSecurity) 属于公开对象模型参考，不能视为本机 Python COM 兼容性证明；以本机独立实例、安全配置、编号保存和 PDF 真实测试为准。
