# V2.0 办公扩展发布说明

状态：功能、集中验证、审查与最终打包完成，远程发布回执见《开发全流程》第 19 章。更新日期：2026-10-12。

## 功能与使用

- 保留 V1.0 Word 精确、非级联替换、安全保存和格式保护；处理阶段增加大小、包结构和源文件变化复查。
- 新增“记录编号”页，支持 WPS/Microsoft Excel 自动化适配、`.xlsx` 全工作表顺序编号，序号至少两位、超过 99 正常增长。
- 自动模式写 E1:F1；固定模式先在每张表顶端插入一行，固定编号写新 E1:F1，递增编号写 E2:F2。目标区域合并、水平/垂直居中、加粗、Times New Roman，使用文字格式。
- 所有工作表必须可见有效；受保护工作表、目标公式、冲突合并或合并时会丢失的数据均拒绝处理。预览后确认已有目标文字的替换。
- 提供仅写编号、仅导出 PDF、一键转换。PDF 使用实际编号产物，所有列一页宽，页高不限，上下边距 1.3 cm、左右 0.9 cm；固定模式修正打印范围，包含新增首行。
- 新增后缀管理页，末尾单次删除或全部匹配删除，保留扩展名；预览目标，冲突避让，执行前复核源文件身份及目标占用。
- 三页参数独立，全程序同时一个批次。取消与关闭等待安全边界，已完成产物保留。

完整操作步骤见项目 README。EXE 自带 Python 依赖；编号和 PDF 仍需要本机安装可用的办公软件。

## 环境与验证

统一使用 PyCharm 的 WordMod 环境：Python 3.13.15，PyQt6 6.11.0、Qt 6.11.2，python-docx 1.2.0、pywin32 312、pypdf 6.20.0、openpyxl 3.1.5、PyInstaller 6.17.0。完整 25 项依赖在 requirements-lock.txt 固定，实际安装无漂移，pip check 无冲突。2026-10-12 复查发现 pypdf 6.17.0 已有已知解析资源消耗漏洞，已升级并再次查询 OSV，锁定版本未返回已知漏洞记录；这不代表未知漏洞不存在。公告依据：[pypdf 官方安全公告](https://github.com/py-pdf/pypdf/security/advisories/GHSA-5jq2-8x83-x246)。

- 自动化：185 项通过，覆盖 Word 原有回归、编号和合并保护、两步转换、源文件与输出保护、危险 Office 输入、预览重命名、线程取消、界面全局互斥与关闭竞态，以及真实 Excel 身份识别与安全打开参数的接口契约。
- WPS 固定模式：三张表全部编号，独立读取核对文字和字体/加粗/居中/合并；原表头下移，公式由 `=B3*2` 正确调整为 `=B4*2`；源文件哈希不变；三页 PDF 均含固定与递增编号。
- WPS 自动模式：三张表编号及 PDF 导出通过，原内容位置不变。
- UI：Windows 原生字体渲染验证 820×700、1000×900、1400×1000；中文、控件和页签可访问。offscreen 平台字体方框不作为 Windows 原生显示结论。
- 修复：空保护节点误判、UTF-16 实体声明检查、COM 调用、插入首行后固定编号不在打印范围、一键默认目录嵌套、关闭预览后任务继续启动，以及新进程恢复用户工作簿时的归属检查。

## Microsoft Excel 验收方法

在安装 Microsoft Excel 的 Windows 机器上打开候选 EXE，选择“记录编号”并将引擎选为“Microsoft Excel”。使用三张可见工作表的测试 `.xlsx`，各表 E1:F1 合并、E1 为旧编号、A1 为原表头、B3 为 12、B4 为 `=B3*2`、打印区域 A1:F5。

1. 选择固定模式，固定编号 `FIXED-编号`，模板 `REC-yy`，起始 99，先预览再一键转换。
2. 检查全部三张表的新 E1、E2 分别为 `FIXED-编号`、`REC-99`，目标合并、居中、加粗且字体 Times New Roman；A2 是原表头，B5 公式为 `=B4*2`。
3. 检查 PDF 含三张表的固定和递增编号，中文完整且不裁切；源文件未修改。
4. 自动模式重复一键转换，确认不插行且所有表 E1 为编号；已有输出不被覆盖。
5. 保持一个用户工作簿打开再执行，确认该工作簿未被修改或关闭。取消批次与处理中关闭窗口应在安全边界结束。

已有 WordMod 开发环境也可运行 `python scripts/verify_office.py --engine excel`，或者通过 `--exe` 参数指向候选 EXE。真实联调报告输出至 build/office-verification；缺少 Microsoft Excel 时不能跳过后宣称通过。
