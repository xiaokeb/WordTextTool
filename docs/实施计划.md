## 架构和首版边界

界面层负责输入、展示和状态管理；文件服务负责发现、过滤、输出路径；替换引擎负责原文快照匹配和 Run 写回；文档处理器负责 OOXML 遍历及安全保存；单个 QThread 负责后台顺序处理与安全取消。

V1.0 只支持 DOCX 正文、表格、页眉页脚及超链接显示文字；支持同段跨 Run 和软换行。采用精确、最长优先、非级联匹配，新文本继承首匹配字符格式。源文件和已有输出不覆盖，无匹配不生成副本。规则两侧各最多 10,000 字符，文档最多 50 MiB。

旧版 DOC 转换、Excel/PDF 模块、文件名修改、跨段落、自动域/文本框等高级区域、规则持久化与导入导出，均标记为首版不实现，候选路线见全流程文档第 15 章。
