# Word 文本处理工具

一个面向 Windows 10/11 的 Word 文档批量文本替换工具。首版使用 Python、PyQt6 与 `python-docx`，重点保证界面响应性、替换结果唯一、原文档安全以及匹配位置的格式继承。

## 当前状态

项目已进入正式开发阶段，直接在根目录 `src/` 中开发。

- 已确认首版范围和交互设计；
- 已建立 `docs/`、`src/`、`dist/` 目录；
- 已实现数据模型、非级联匹配、跨 Run 格式继承和 DOCX 区域遍历；界面与打包尚在开发；
- Excel 编号、PDF 导出和文件名后缀修改不属于首版。

## 首版范围

- 使用 PyQt6 构建可缩放的单页桌面界面；
- 批量选择或从单层文件夹扫描 `.docx` 文档；
- 通过只读两列表格展示用户动态添加的替换规则；
- 处理正文、普通及嵌套表格、页眉、页脚和超链接显示文字；
- 支持同一段落内跨 Run 和软换行的文本匹配；
- 使用非级联、从左到右、同位置最长优先的替换算法；
- 新文本继承匹配首字符的格式，未匹配内容保持原格式；
- 后台顺序处理文件，支持进度显示和安全取消；
- 永不覆盖源文件或已有输出文件。

旧版 `.doc` 文件在首版中会被识别并提示，但不会加入处理队列。
